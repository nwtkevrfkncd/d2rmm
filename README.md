## Overview

D2RMM provides a GUI for installing, ordering, and merging Diablo II: Resurrected mods, resolving JSON conflicts automatically so multiple mods coexist without manual file patching.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D2RMM** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Mod Installer** | Drag-and-drop mod installation with automatic load-order sorting |
| **JSON Merger** | Intelligently merges conflicting JSON changes from multiple mods |
| **Profile System** | Save and switch between different mod load-out profiles |
| **Update Checker** | Notify when installed mods publish new versions on Nexus Mods |
